# QuizNova — Mani's Quiz Lab

An interactive Online Quiz Application built using HTML, CSS and vanilla JavaScript.

## Features
- Multiple-choice questions and answer selection
- Tech & Coding and Science Mix categories
- Automatic score calculation and final result screen
- Question counter and progress indicator
- Immediate feedback and answer explanations
- Responsive design for mobile, tablet and desktop
- Dark/light theme toggle and replay controls

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
Upload `index.html`, `style.css`, `script.js`, and `README.md` to the root of a public GitHub repository. Then open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, and click **Save**.
